# 1. 목적 (Purpose)
음성(TTS)으로 들을 때 자연스럽고 한눈에 이해하기 쉽도록, 마크다운 기호나 복잡한 표 형태 대신 구어체(Conversational Spoken Korean)로 요약된 1분 음성 브리핑 문장을 생성합니다.

# 2. 입력 (Input)
- `일정/To-Do/회의록`: 요약 및 브리핑 대상 원문 데이터

# 3. 절차 (Procedure)
1. 원문 데이터에서 [오늘의 핵심 1~2개 일정], [마감 기한 임박 과제], [필요 조치]를 추출합니다.
2. 기호(`*`, `#`, `-`, `|`) 및 마크다운 특수문자를 모두 제거합니다.
3. 귀로 들었을 때 자연스러운 경어체 문장(~입니다, ~가 있습니다)으로 다듬습니다.
4. 총 분량을 읽기 기준 30초~1분 이내(3~4문장)로 압축합니다.

# 4. 출력 (Output)
```text
안녕하세요. 오늘의 핵심 브리핑입니다.
오전 10시에 디자인 리뷰 회의가 있으며, 오후 3시까지 클라이언트 보고서 전달이 예정되어 있습니다.
확인이 필요한 미결 과제는 총 1건입니다. 브리핑을 마치겠습니다.
```

# 5. 실패 처리 (Fallback)
- 원문 내용이 없는 경우: "전달받은 일정이 없습니다. 새로 등록할 일정을 말씀해 주세요."라고 응답합니다.
