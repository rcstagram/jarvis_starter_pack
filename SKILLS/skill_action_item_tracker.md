# 1. 목적 (Purpose)
대화, 회의록, 이메일 본문, 메모 텍스트에서 후속 조치가 필요한 실행 과제(Action Items)를 정밀 분석하여 담당자, 마감 기한, 현재 상태, 비고가 포함된 표준 마크다운 구조로 구조화합니다.

# 2. 입력 (Input)
- `원문 텍스트`: 회의록, 대화록, 이메일, 음성 텍스트 녹취록 등

# 3. 절차 (Procedure)
1. 원문 텍스트에서 동사 구문(~하기로 함, ~제출 예정, ~담당, ~까지 완료 등)을 찾아 실행 과제(Action Item)로 정의합니다.
2. 각 실행 과제별로 [과제 내용, 담당자, 마감일, 관련 종속성/참고 사항]을 파싱합니다.
3. 담당자나 마감일이 명시되지 않은 경우, "미지정 (확인 필요)" 표기를 부여합니다.
4. 중복되거나 모호한 과제는 하나로 통합하고 명확한 행동 양식(Action Verb)으로 다듬습니다.

# 4. 출력 (Output)
```markdown
### 📝 Action Items 목록

| ID | 실행 과제 (Action Item) | 담당자 | 마감 기한 (Due Date) | 상태 | 비고 / 종속성 |
|:--:|:-----------------------|:------:|:--------------------:|:----:|:-------------|
| AI-01 | [동사 형태의 실행 과제] | [담당자] | [YYYY-MM-DD] | 대기 | [관련 정보] |
| AI-02 | [동사 형태의 실행 과제] | [미지정] | [확인 필요] | 대기 | [담당자/기한 재확인 필요] |

#### ❓ 담당자/기한 확인이 필요한 항목
- **AI-02**: 과제 [과제명]의 담당자 및 완료 목표일을 지정해 주세요.
```

# 5. 실패 처리 (Fallback)
- 원문 텍스트에서 실행 과제를 찾을 수 없을 경우: "제시된 내용에서 명시적인 실행 과제(Action Item)가 발견되지 않았습니다. 추가 논의 사항이나 지시 내용을 알려주시면 재분석하겠습니다."라고 응답합니다.
