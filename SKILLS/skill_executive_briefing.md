# 1. 목적 (Purpose)
사용자의 하루/주간 업무 흐름을 한눈에 파악할 수 있도록 핵심 이슈, 일정, 확인 필요 항목, 위험 요소를 1분 브리핑 형태로 요약 생성합니다.

# 2. 입력 (Input)
- `일정/메모/업무목록`: (예: 금일 일정, 미결 과제 리스트, 이메일 요약 등)
- (선택) `브리핑 모드`: `daily` (기본값) | `weekly` | `urgent`

# 3. 절차 (Procedure)
1. 입력받은 메모 및 일정 데이터를 긴급도(Urgency)와 중요도(Importance)로 분류합니다.
2. 당일/당주 반드시 처리해야 하는 Top 3 핵심 과제를 상단에 배치합니다.
3. 타인이나 외부 검토를 기다려야 하는 '확인 필요 사항'을 별도로 분리합니다.
4. 일정 지연, 리소스 부족 등 잠재적 위험 요소를 1문장으로 요약합니다.

# 4. 출력 (Output)
```markdown
# 📅 [Daily/Weekly Briefing] YYYY-MM-DD

## 🎯 오늘의 핵심 Top 3
1. [과제명] - [주요 목표 / 마감시간]
2. [과제명] - [주요 목표 / 마감시간]
3. [과제명] - [주요 목표 / 마감시간]

## 📌 주요 일정 및 To-Do
- [ ] HH:MM - [일정/회의명] (참석자 / 장소)
- [ ] HH:MM - [일정/회의명] (참석자 / 장소)

## ❓ 결정 및 확인 필요 사항 (Decision Required)
- [ ] [확인 항목] : [의사결정이 필요한 이유 및 선택지]

## ⚠️ 잠재적 리스크 & 주의사항
- [주의사항/리스크 내용 1줄 정리]
```

# 5. 실패 처리 (Fallback)
- 입력 데이터가 불충분할 경우, 기본 템플릿 틀을 제공하고 "입력된 일정이 적습니다. 추가할 일정이 있으신가요?"라고 질의합니다.
