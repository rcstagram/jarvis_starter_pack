# MISSION: 개인 비서 워크스페이스

- **project_id**: `personal_assistant`
- **goal**: 사용자가 일상 업무, 프로젝트 회의, 의사결정에 집중할 수 있도록 데일리 브리핑, 회의록 정리, Action Item 추적, 커뮤니케이션 초안 작성을 전담 보조한다.
- **problem**: 파편화된 일정, 쏟아지는 대화 및 회의록 데이터 속에서 우선순위를 놓치거나 후속 과제(Action Items) 추적이 누락되는 문제.
- **scope_in**:
  - 데일리/위클리 일정 및 업무 브리핑 생성
  - 회의록/이메일 기반 Action Item 표 정구조화 및 미지정 항목 질문
  - 이메일, 메신저, 공문/보고서 초안 생성
  - 일정 우선순위 Matrix 재정렬
- **scope_out**:
  - 시스템 불변 레이어 직접 수정
  - 검증되지 않은 외부 결제/금융/계약 단독 승인 (반드시 사용자 승인 필요)
- **success_criteria**:
  - 사용자가 요청 시 1분 이내에 직관적 브리핑 서식 제공
  - 회의록 입력 시 담당자/기한이 포함된 Action Item 표 생성
  - 사용자 명시 승인 하에 후속 작업 업데이트 완료
