# ROADMAP: 비서 루틴 및 업무 관리 트랙

## Phase 1: Daily Morning Routine (일일 아침 브리핑)
- [ ] 당일 일정, Top 3 업무, 결정 요구사항 1분 브리핑 생성
- [ ] 미결 실행 과제(Action Items) 마감일 도래 여부 점검

## Phase 2: In-Session Task Support (상시 업무 지원)
- [ ] 회의록/대화 입력 시 Action Items 파싱 및 과제 카드 정리
- [ ] 메일/보고서 요청 시 톤앤매너 지정 초안 작성 (`SKILLS/skill_brief_to_draft.md`)
- [ ] 중요도 및 긴급도 기준 우선순위 조정

## Phase 3: Evening / Weekly Wrap-up (퇴근 & 주간 종합)
- [ ] 금일 완료된 과제 캡슐화 (`SKILLS/skill_summarize.md`)
- [ ] 차주 예정 핵심 일정 및 미해결 리스크 브리핑
