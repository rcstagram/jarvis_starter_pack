# Jarvis Desktop App Starter (Python 데스크톱 GUI 애플리케이션)

이 모듈은 웹 브라우저 탭에 의존하지 않고, macOS 독립 윈도우 창(Native Desktop Application Window)으로 실행되는 **Python 기반 Jarvis 데스크톱 애플리케이션**입니다.

---

## 🛠️ 주요 기능
1. **독립 데스크톱 윈도우 창**:
   - `pywebview` 및 macOS Cocoa Native WebKit 프레임 기반 1280x800 풀사이즈 창 구동
2. **비전 및 카메라 Privacy Control**:
   - 카메라 On/Off 토글 버튼 (`📷 VIDEO ON / OFF`)을 내장하여 개인정보 보호 완전 차단 모드 지원
3. **3D AI 파티클 코어 & 음성 자막**:
   - 하이엔드 3D 파티클 구체, 실시간 음성 자막 배너, 오디오 비주얼라이저 파형 내장
4. **Python API 브리지**:
   - 데스크톱 창 내부 버튼 및 입력이 Python 백엔드 스크립트와 일체형으로 연동

---

## 🚀 실행 방법

```bash
python3 01_Modules/Jarvis_Desktop_App_Starter/jarvis_app.py
```
